Acerca de este proyecto

Este proyecto fue desarrollado con Python y Django como parte del curso de Coderhouse.

La aplicación permite gestionar productos, crear usuarios, iniciar sesión y administrar diferentes permisos.

También incluye perfiles de usuario, búsqueda de productos y formularios con validación.
